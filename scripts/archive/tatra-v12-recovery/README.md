# Archived Tatra V12 recovery tooling

These scripts are preserved for forensic/recovery history only. They are not part of the active PINK CAB build, cook, import, or verification path.

Active Tatra tooling in `scripts/` is intentionally minimal:
- `build_tatra_v12_wheel.py`
- `import_tatra_v12_wheel.py`
- `export_tatra_scene_preserved.py`
- `import_tatra_scene_preserved.py`

Runtime presentation authority is ScenePreserved for body/cockpit/steering plus the validated V12Clean wheel. Archived full-body/full-steering V12 variants must not be reintroduced without an explicit asset-pipeline change and fresh verification.
